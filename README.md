# PARKTRING - Family Vacation

PARKTRING is a simple Python program that helps you plan a trip. It puts several travel tools in one menu, so you don't have to spend the day searching for prices, companies and travel info.

## Features

| Option | File | What it does | Author |
|--------|------|--------------|--------|
| 1 | `passport.py` | Shows the countries you can travel to with your passport | Samuel |
| 2 | `best_price.py` | Finds the lowest price in a list of prices | Yerover |
| 3 | `best_company.py` | Finds the best rated rental company | Álvaro |
| 4 | `health.py` | Shows the diseases of a country and how to prevent them | Nuhazet |
| 5 | `overbooking.py` | Checks if a flight is overbooked | Antonio |

`main.py` is the main menu. It lets you choose which tool to run.

## How to run

You only need Python 3.9 or higher. No extra libraries are required.

1. Download all the files into the same folder.
2. Open a terminal in that folder.
3. Run the main menu:

```
python main.py
```

You can also run any tool on its own, for example:

```
python health.py
```
